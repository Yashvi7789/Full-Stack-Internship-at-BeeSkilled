## Week 2 – Backend Development

Completed three backend projects focused on Node.js, Express.js, MongoDB, REST APIs, and authentication.

| Project | Description | Technologies |
|---|---|---|
| To-Do List REST API | REST API to create, retrieve, update, and delete tasks using MongoDB. | Node.js, Express.js, MongoDB, Mongoose |
| User Authentication API | User registration and login with password hashing and JWT authentication. | Node.js, Express.js, MongoDB, bcryptjs, JWT |
| Notes App Backend | Secure notes management API with CRUD operations and JWT-protected routes. | Node.js, Express.js, MongoDB, Mongoose, bcryptjs, JWT |

### Key Learnings

- Node.js and npm fundamentals
- Express.js server setup and routing
- REST API development
- MongoDB database integration
- Mongoose schemas and models
- CRUD operations
- Password hashing using bcryptjs
- JWT-based authentication and authorization
- Protected API routes
- API testing using Postman
- Environment variables and Git security
