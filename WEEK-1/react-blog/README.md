# React Blog Application

A responsive blog application built using React.js. This project helps demonstrate component-based development, form handling, and dynamic content rendering.

## Features

- Display blog posts.
- View individual blog details.
- Add new blog posts using a form.
- Reusable React components.
- Organized blog data using JSON.
- Responsive user interface.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## Installation and Setup

1. Open the project folder in VS Code.
2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open the local URL shown in the terminal.
