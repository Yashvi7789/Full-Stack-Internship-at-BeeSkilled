# Personal Portfolio Website

A personal portfolio website developed using HTML and CSS to showcase my profile, educational background, technical skills, and projects.

## Features

- Personal introduction.
- Education details.
- Technical skills.
- Project showcase.
- Contact information.
- Clean and user-friendly design.

## Technologies Used

- HTML5
- CSS3

## Project Structure

```text
yashvi-portfolio/
├── index.html
├── style.css
└── README.md
```

## How to Run

1. Open the `yashvi-portfolio` folder.
2. Open `index.html` in your web browser.
3. Explore the portfolio website.
