# Week 1 – Full Stack Development Internship

This folder contains the three projects completed during **Week 1** of my Full Stack Development Internship at **BeeSkilled**.

The projects helped me understand React fundamentals, reusable components, form handling, frontend development, and website design.

---

## 📂 Projects

### 1. React Blog Application

**Folder:** `react-blog`

A React-based blog application where users can explore blog posts and view individual blog details.

**Key Features:**
- Display blog posts using reusable components.
- Blog cards with post information.
- Add new blog posts through a form.
- View individual blog details.
- Organized project structure.

**Technologies Used:**
- React.js
- JavaScript
- HTML
- CSS
- Vite
